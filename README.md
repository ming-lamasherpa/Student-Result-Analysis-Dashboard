# 🎓 Student Result Analysis System

A simple and interactive **Student Result Analysis System** built using **Python, Streamlit, and Pandas**. 
This application allows users to upload student result data in CSV format and perform various analyses such as viewing raw data,
finding toppers, searching students, subject-wise performance, pass/fail analysis, and pivot tables.

# First create virtual environment
#### -> python -m venv venv
#### -> pip install streamlit
#### -> pip install pandas
#### -> pip install streamlit-option-menu

# Command to run streamlit
#### -> streamlit run project.py
